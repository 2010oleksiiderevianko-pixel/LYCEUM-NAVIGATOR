# LYCEUM NAVIGATOR — NEON EDITION + JARVIS

Демонстраційний вебзастосунок для перегляду схем корпусів і побудови маршрутів. JARVIS — серверний ШІ-помічник із голосовим вводом/озвученням та контрольованими командами для навігатора.

## 1. Встановлення та запуск JARVIS (Windows)

1. Встанови Python 3.10 або новіший.
2. Розпакуй архів і відкрий папку `LYCEUM-NAVIGATOR-NEON`.
3. Запусти `start-jarvis.bat` або виконай команди вручну:

```bash
py -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
copy .env.example .env
```

4. Відкрий `.env` і встав свій ключ у `OPENAI_API_KEY`. Не надсилай ключ у чат, не додавай його в `index.html`, JavaScript або GitHub.
5. Запусти `python server.py`.
6. Відкрий `http://localhost:5000` у Chrome або Edge. Не запускай `index.html` подвійним кліком — для JARVIS потрібен сервер.

Потрібні інтернет і власний API-доступ до сумісної з OpenAI Chat Completions моделі. За замовчуванням використовується `gpt-4o-mini`; назву можна змінити в `.env`. Вартість API залежить від провайдера, моделі й обсягу запитів. API-ключ не входить до архіву.

## 2. Можливості JARVIS

- Вільний діалог із моделлю ШІ та коротка історія поточної розмови.
- Голосове введення українською через Web Speech API (підтримка залежить від браузера та дозволу на мікрофон).
- Озвучення відповідей українською через синтез мовлення браузера.
- Передача каталогу приміщень як контексту, команди відкрити розділ, пошук приміщення та підготовка маршруту.
- Серверна перевірка дозволених дій; ключ API залишається на сервері.
- Статус підключення та повідомлення про помилки.

Голосові функції можуть вимагати HTTPS або localhost і дозволу браузера. JARVIS не має доступу до комп'ютера, файлів чи мікрофона без явної дії та дозволів користувача.

## 3. Конфігурація API

`.env.example` — шаблон. Скопіюй його у `.env` та задай:

- `OPENAI_API_KEY` — секретний ключ провайдера.
- `OPENAI_MODEL` — назва доступної моделі.
- `OPENAI_BASE_URL` — необов'язкова адреса OpenAI-сумісного API.
- `PORT` — порт локального сервера (за замовчуванням 5000).

Не публікуй `.env`. Файл уже додано до `.gitignore`.

## 4. Навігатор

- Навігація між приміщеннями на демонстраційній схемі.
- Корпус А/Б: 1–4 поверхи; В, Г, Е: демонстраційні схеми 1-го поверху.
- Четвертий поверх А/Б повторює геометрію третього як непідтверджене демонстраційне припущення.
- Масштабування, пошук приміщень, геолокація, налаштування теми й QR-код.

## Важливо

Схеми, номери кабінетів, проходи та міжповерхові зв'язки демонстраційні й не підтверджені адміністрацією ліцею. Між корпусами переходи не вигадані. Не використовуй застосунок для евакуації або як офіційне джерело навігації.

## Структура

- `index.html` — розмітка
- `css/style.css` — оформлення
- `js/data.js` — дані корпусів і приміщень
- `js/engine.js` — пошук і алгоритм Дейкстри
- `js/map.js` — SVG-схема та керування
- `js/app.js` — інтерфейс і навігація
- `js/assistant.js` — чат, голос і команди JARVIS
- `server.py` — серверний API-посередник для ШІ
- `.env.example` — шаблон конфігурації (секретний `.env` не включати в репозиторій)
